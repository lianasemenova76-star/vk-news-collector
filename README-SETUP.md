# VK News Collector

Сборщик раз в сутки получает открытые публикации из `vk.ru/tutaev` за последние 24 часа.

## Что уже настроено

- источник: `tutaev`;
- ручной запуск из GitHub Actions;
- автоматический запуск ежедневно в 03:15 UTC (06:15 по Москве);
- текущая выгрузка: `data/latest.json`;
- ежедневный архив: `data/archive/YYYY-MM-DD.json`;
- токен читается только из секрета `VK_SERVICE_TOKEN`.

## Первый запуск

1. Загрузить содержимое этой папки в корень репозитория.
2. Открыть вкладку **Actions**.
3. Выбрать workflow **Collect VK news**.
4. Нажать **Run workflow**, затем ещё раз **Run workflow**.
5. Дождаться зелёной галочки.

После успешного запуска в репозитории появится папка `data`.
