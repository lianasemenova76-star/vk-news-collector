# vk-news-collector

Автоматизация группы VK «Тутаев | Главные новости округа».

## Возможности

- сбор новостей в `data/latest.json`;
- публикация и отложенная публикация только из подтверждённого `publish-request.json`;
- публикация с изображением из каталога `media/` через поле `image_path`;
- добавление изображения к любой подтверждённой записи;
- статистика публикаций;
- ежедневный сбор комментариев к публикациям за последние семь дней;
- ежедневная подготовка черновика погоды для Тутаева на сегодня и завтра.

Сценарии комментариев и погоды ничего не публикуют и не отвечают пользователям. Их результаты сохраняются как закрытые артефакты GitHub Actions на семь дней.

## Пост с изображением

```json
{
  "confirmed": true,
  "posts": [
    {
      "message": "Текст одобренного поста",
      "image_path": "media/example.png",
      "publish_date": 1786330800
    }
  ]
}
```

`publish_date` необязателен. Изображение должно находиться внутри `media/`.
