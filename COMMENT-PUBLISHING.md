# Ответы на комментарии от имени «Мой Тутаев»

Автоматизация относится **только** к собственной стене сообщества VK с доменом **vtutaeve**. Комментировать записи других сообществ через этот сценарий нельзя.

## Как отправить

1. Подготовить и одобрить **точный** текст и целевой пост/комментарий.
2. Изменить `comment-publish-request.json` в основной ветке (через ChatGPT после явного одобрения или вручную), указав новый `request_id`, `confirmed: true`, `post_id`, `message` и при необходимости `reply_to_comment`.
3. Коммит изменения файла автоматически запускает `.github/workflows/publish-comment.yml`. В журнале появится URL ответа `https://vk.ru/wall-<group_id>_<post_id>?reply=<comment_id>`.

### Пример структуры (не отправлять без одобрения)

```json
{
  "confirmed": false,
  "request_id": "",
  "post_id": null,
  "reply_to_comment": null,
  "message": ""
}
```

- `confirmed` должен быть строго `true` для публикации. По умолчанию `false`.
- `request_id` должен быть новым для каждого **отдельно согласованного** ответа (8–64 символа: латинские буквы, цифры, `-`, `_`). Он используется в стабильном VK `guid` для защиты от дублей при повторном запуске.
- `post_id` — числовой ID записи группы (из ссылки `wall-<group_id>_<post_id>`), обязательный.
- `reply_to_comment` — числовой ID комментария, на который отвечаем, или `null` для нового комментария под постом.
- `message` — согласованный текст, от 1 до 4000 символов.
- `owner_id` и `from_group` задавать нельзя: автор и сообщество определяются самим скриптом.

## Защита

- Публикация возможна только при одновременном наличии `confirmed: true`, параметра запуска `--send` и переменной `CONFIRM_COMMENT=YES`.
- `--validate` работает без запросов к VK и без публикации.
- Скрипт сверяет, что пост принадлежит стене **vtutaeve**.
- Автор комментария передаётся в VK API как `from_group=1`.
- Используются уже настроенные GitHub Actions secrets: сначала `VK_USER_TOKEN`, затем `VK_PUBLISH_TOKEN`, если пользовательский токен отсутствует. Значения секретов не записываются в репозиторий.
- В случае ошибки прав доступа или настроек VK API комментарий **не** считается отправленным; проверять статус в GitHub Actions.
- Автоматическое чтение комментариев в `comments.py` остаётся только чтением.

**Важно:** изменение файла заявки с `confirmed: true` является действием публикации. Не коммитить такой запрос без прямого согласия автора текста. Живую отправку проверять только на отдельно одобренном комментарии.
